## Overview

Depo Tool is an open-source Steam library manager designed for transparency, performance, and simplicity.

It allows users to seamlessly integrate supported game packages into their Steam library through an automated and structured process.

No telemetry.  
No tracking.  
Fully auditable source code.

---


## Features

- Fully open source  
- Transparent and auditable codebase  
- Modern UI built with Tauri  
- Automated manifest & Lua handling  
- Dual server infrastructure (Cloudflare + GitHub)  
- Automatic updates  
- Clean and minimal interface  
- Windows desktop support  

---

## How It Works

1. **Search**  
   Locate supported titles using Steam App IDs.

2. **Download**  
   Required packages are retrieved through redundant CDN infrastructure.

3. **Extraction**  
   Manifest and Lua files are automatically structured into the correct Steam directories.

4. **Integration**  
   The game becomes available inside the Steam client.
